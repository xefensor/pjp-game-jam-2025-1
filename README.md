# PJP GAME JAM 2025-1 game postmortem

This game was ment to be a detective game where you are placed behind a keyboard that represents a map with number keys representing times of day and abc keys playing a sound.

You would have listen to the different sounds, make a map of the city by the sound of keys and figure out where and when and whose stole something.

For example you can figire out the time of day by the clock tower that rings on the letter K.

I was setting it up that there would be a robbery in museum on letter E at 7 key.

The game would be won be correctly guessing some questions like:

- Who stole it?
- When?
- Where?
- Where did they put it?

You would also be following throughout the day five people that each can be recognized only by sound:

- guitarist
- smoker witch a lighter
- person with rattling keys
- person with mobile phone
- skateboardist
